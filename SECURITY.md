# Security policy

## Supported versions

Security fixes are applied to the latest release.

## Reporting a vulnerability

Do not open a public issue for credentials exposure, unsafe remote control, or
another exploitable vulnerability. Use GitHub's **Report a vulnerability**
button in the repository Security tab. Include the affected version, impact,
reproduction steps, and any suggested mitigation.

Operational failures that do not expose a vulnerability, such as a valve not
closing after a device becomes unavailable, may be filed as regular bugs after
removing entity IDs, addresses, and other private installation details.
